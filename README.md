# Ricardo Escalante — IT & Cloud Support Portfolio

A responsive, single-page portfolio and printable résumé for Ricardo Escalante, focused on remote IT support, help desk, cloud support, and systems administration opportunities.

## Pages

- `index.html` — portfolio, education, certifications, projects, skills, and contact details
- `resume.html` — responsive résumé with a print-optimized PDF layout

## Run locally

No build step is required. Open `index.html` directly, or serve the directory:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Stack

- Semantic HTML
- Tailwind CSS via CDN
- Small vanilla JavaScript enhancements
- Font Awesome icons

## Deployment

The site can be deployed as static files with GitHub Pages, Netlify, Cloudflare Pages, or any standard web host.
